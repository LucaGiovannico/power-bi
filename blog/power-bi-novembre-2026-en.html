Power BI November 2026: 8 updates you should know

The key Power BI updates for November 2026 explained in practical terms, from the new Semantic Views and trend charts in Cards to report formatting improvements and the evolution of Microsoft Copilot.

Context

Power BI continues to evolve with updates that improve report creation, semantic model management, and integration with Microsoft Fabric tools.

After an October release focused mainly on visualizations and the user experience, the November 2026 update introduces features designed to make reports more consistent, simplify development, and improve data management across different environments.

Among the new features are trend charts integrated into Cards, reusable formatting styles, Semantic Views, and new AI-assisted development capabilities.

Let's look at eight updates worth knowing about and how they can make a difference in everyday work.

1. Semantic Views: a new way to define business data

One of the most interesting updates in November is the introduction of Semantic Views, available in preview in Microsoft Fabric.

This feature allows organizations to define shared tables, relationships, and business metrics through a centralized semantic layer.

When a Semantic View is published, a managed, read-only Direct Lake on OneLake semantic model is created, while the view remains the main source of definitions.

The benefit is the ability to define business concepts and KPIs once and reuse them across reports and other analytical tools.

Consider, for example, a company that uses the same revenue KPI across multiple reports. Centralizing the metric definition can help prevent different departments from interpreting it differently.

Semantic Views therefore represent an interesting step forward in maintaining data consistency, particularly in more structured Microsoft Fabric environments.

2. Trend charts directly within Cards

Power BI Cards become more informative with the introduction of Trend Charts, available in preview.

This new feature allows users to add a chart directly within a Card, displaying the main KPI value alongside a visual representation of its trend over time.

Using the Trend axis field, users can configure visualizations such as line, bar, or column charts, as well as supported geographic representations.

Formatting options are also available for labels, markers, axes, and tooltips.

For example, a Card displaying total revenue can include a small chart showing sales performance over recent months.

This way, users don't just see the current value. They can immediately understand whether the KPI is increasing, decreasing, or remaining stable.

This improvement is particularly useful for executive dashboards, where space is limited and each visual needs to communicate information quickly.

3. Reusable formatting styles for visuals

Another important update concerns Visual Style Presets, which are now generally available.

Power BI allows users to save a visual's formatting as a reusable style and apply it to other elements within the report.

Styles can also be set as defaults and distributed through custom themes.

This makes it possible to define consistent settings for colors, fonts, borders, and other visual elements, reducing the need to repeat the same formatting tasks manually.

For example, a company can create a standard style for column charts and use it across all reports designed for management.

The feature also allows users to reset manual formatting changes without necessarily removing conditional formatting or configured actions.

The benefit is twofold: greater visual consistency and less time spent on formatting.

For those developing multiple business reports, this update can make it easier to maintain shared design standards.

4. Filters directly within tables and matrices

November introduces a new way to interact with visual-level filters.

With Visual Action Buttons, available in preview, users can add a filter button directly to tables and matrices.

This allows users to view and modify the filters applied to a specific visual without necessarily opening the Filters pane.

Page-level and report-level filters continue to be managed through the traditional Filters pane.

Consider a matrix showing sales by product and geographical area.

Users can adjust the matrix filters directly while keeping the visualization in context.

This improvement can make reports more intuitive, particularly for less experienced users.

In the same update, the List slicer reaches general availability, including dropdown mode, multi-row selection labels, and the option to display selected values first.

5. M parameters in Direct Lake on OneLake models

A particularly interesting update for developers is the introduction of M parameter support in Direct Lake on OneLake models, available in preview.

These parameters can be used with deployment pipeline rules to change data source references across different environments.

For example, a model can be configured to use different OneLake data sources in development, testing, and production environments.

Previously, managing these differences could require manual changes to source expressions.

With the new support, moving between environments becomes easier and more controlled.

This is particularly useful for business projects that follow structured deployment processes and need to keep development and production environments separate.

6. OneDrive and SharePoint integration is now generally available

Power BI integration with OneDrive and SharePoint has reached general availability.

Users can view PBIX files directly in the browser and use Power BI Desktop to open, save, and share files through these platforms.

This simplifies project file management, especially when multiple people need access to the same files.

The integration also makes it possible to take advantage of features such as version history and the sharing options provided by OneDrive and SharePoint.

For teams working on shared reports, this means better file organization and less need to manage multiple local copies across different users.

It's important to remember that sharing PBIX files doesn't replace development version control systems such as Git and PBIP, but it can be useful for day-to-day file management.

7. Power BI Desktop for Apps: new AI-assisted applications

Microsoft has also announced Power BI Desktop for Apps, a new preview experience designed to create interactive applications based on semantic models.

The goal is to go beyond traditional reports, allowing developers to build application experiences using visual tools and artificial intelligence.

Planned capabilities include AI-assisted creation through natural language instructions, direct text editing, a Design pane, and local application previews.

For example, starting from a sales semantic model, a developer could design an application for exploring KPIs and operational information.

This feature represents an interesting evolution within the Microsoft Fabric ecosystem, bringing data analysis and business applications closer together.

However, this is an announced experience that is not yet generally available. Its actual capabilities will therefore need to be evaluated once the release becomes accessible.

8. Microsoft Copilot: changes to the Power BI experience

The November update also introduces an important change in Microsoft's artificial intelligence strategy.

Microsoft has announced that the standalone Power BI Copilot experiences on the web, in Teams, and in the mobile app will be retired by the end of January 2027.

App-scoped Copilot in workspace apps is also scheduled for removal in January 2027.

This doesn't mean Copilot is being removed from Power BI.

Copilot features integrated into supported reports will remain available, while Microsoft is gradually shifting the experience toward Microsoft 365 Copilot and new Fabric integrations.

For organizations already using Copilot, it's therefore important to review which experiences are currently in use and plan any necessary transition to the new options.

This change confirms a clear direction: Microsoft wants artificial intelligence to become more deeply integrated into everyday work rather than remain a separate feature within individual products.

In practice

What actually changes in everyday work

The November 2026 update introduces improvements that affect both report developers and the people who use reports to analyze data.

The new Trend Charts in Cards make it possible to enrich dashboards without necessarily increasing the number of visuals, while Style Presets simplify visual standardization.

Filters directly within tables and matrices make interacting with data more immediate, particularly in reports designed for business users.

On the modeling side, Semantic Views and M parameter support in Direct Lake models introduce new possibilities for managing shared definitions and more structured deployment processes.

OneDrive and SharePoint integration improves file management, while Power BI Desktop for Apps and the evolution of Copilot show how Microsoft is expanding the role of artificial intelligence.

Overall, a clear trend is emerging: Power BI is no longer just a tool for creating dashboards. It is increasingly becoming part of an integrated ecosystem for managing and using business information.

In summary

In summary

Among the November 2026 Power BI updates, trend charts in Cards and reusable formatting styles represent practical improvements to report design.

Semantic Views introduce new ways to centralize data definitions, while M parameters in Direct Lake models simplify data source management across different environments.

OneDrive and SharePoint integration reaches general availability, making PBIX file management easier.

On the artificial intelligence side, Power BI Desktop for Apps and the announced Copilot changes confirm the move toward experiences that are increasingly integrated with Microsoft Fabric and Microsoft 365.

As always, the value of these updates doesn't depend on the number of features introduced, but on how effectively they can be used to improve analytical processes.

Reliable models, consistent KPIs, and reports designed around user needs remain essential for turning data into useful information.
