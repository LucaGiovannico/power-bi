Power BI October 2026: 7 updates you should know

The key Power BI updates for October 2026 explained in practical terms, from the new built-in Gantt chart and slicer improvements to artificial intelligence and semantic model resource optimization.

Context

Power BI continues to evolve with updates that improve report creation, data exploration, and resource management.

After a September release packed with improvements, particularly in modeling and artificial intelligence, the October 2026 update focuses more on reporting capabilities and dashboard usability.

Among the new features are a built-in Gantt chart, more flexible slicers, improvements to hierarchy management, and new ways to use artificial intelligence in report development.

Let's look at seven updates worth knowing about and how they can make a difference in everyday work.

1. New built-in Gantt chart in Power BI

One of the most interesting updates in October is the introduction of a built-in Gantt chart visual in Power BI, currently available in preview.

Until now, displaying project schedules using a Gantt chart often required custom visuals from AppSource.

The new visual makes it possible to display tasks, durations, progress, and milestones along a timeline directly within a report.

Available features include customizable time intervals, category-based colors, additional information columns such as task owner and status, and zoom controls to focus on specific periods.

To enable it in Power BI Desktop, go to File → Options and settings → Options → Preview features, enable the Gantt visual, and restart the application.

This is particularly useful for organizations using Power BI for project management, tracking project progress, or planning business activities.

2. List slicer with dropdown mode and more intuitive filtering

October also introduces several improvements to report filtering.

The List slicer, still in preview, now supports a dropdown mode that makes it easier to manage long lists of values without taking up too much space on the report page.

Selected values appear as removable labels, allowing users to immediately see which filters are active.

The new Show selected first option moves selected values to the top of the list. The same feature is also supported by the Button slicer.

Microsoft has also improved dropdown size customization and search box formatting.

Another useful improvement concerns exclusions. When users select all values and then deselect specific items, Power BI clearly displays which values have been excluded.

These updates can significantly improve navigation in reports containing large numbers of products, customers, categories, or geographical areas.

3. Dynamic hierarchies with Field Parameters

Another improvement concerns hierarchy management on chart axes.

Power BI now supports automatic hierarchy expansion even when fields are managed through Field Parameters.

The feature is generally available and applies to bar, column, and line charts.

Field Parameters allow users to dynamically change the dimensions displayed in a visual. With the new behavior, when multiple fields are selected, Power BI can automatically build and expand the hierarchy on the axis.

For example, a sales report could allow users to switch from sales by country to a hierarchy including country, segment, and product, without requiring separate charts.

This makes it possible to design more flexible dashboards, reduce the number of visuals needed, and give users greater freedom to explore the data.

4. New formatting options for chart plot areas

With the October update, plot area background color customization reaches general availability.

The feature applies to several visual types, including bar, column, line, area, combo, ribbon, waterfall, and scatter charts.

In addition to setting a solid color and transparency level, users can apply conditional formatting based on a measure or field value.

This makes it possible to dynamically change the chart's plot area background based on the data.

For example, a DAX measure could be used to apply a different background when a KPI exceeds a specific threshold.

It may seem like a small improvement, but it can help highlight specific situations and make information easier to interpret, provided colors are used carefully.

5. Personal Bookmarks now preserve column sizes

Personal Bookmarks become more useful with the ability to save column widths and column order in tables and matrices.

Previously, users could customize how a table was displayed, but the same column layout was not always restored when applying a bookmark.

With this update, changes to column widths and order are preserved in the personal bookmark.

Consider a financial report containing a matrix with several financial indicators.

Each user can arrange the columns according to their needs, save the configuration, and restore it later without repeating the changes.

This is especially useful for reports accessed daily, where personalized layouts can improve productivity.

6. AI agents now support custom visuals

Microsoft continues to expand the artificial intelligence capabilities available for report development.

In October, the Power BI Report Authoring skill within Skills for Fabric extends its support to custom visuals and is now generally available.

AI agents can assist developers with adding custom visuals, assigning model fields, configuring formatting options, and validating the results.

The feature can work with visuals already imported into the report and help identify components available through AppSource.

For example, when a report requires a specialized visualization that is not included among the standard options, an agent can assist with configuration tasks based on natural language instructions.

Support still depends on visual compatibility and the tools available.

This improvement continues the direction established in previous months: artificial intelligence is being used not only to query data but also to accelerate development tasks.

However, it remains essential to verify that the selected visual is appropriate, reliable, and aligned with the objectives of the analysis.

7. More accurate semantic model resource management

The final update concerns a less visible but important aspect of Microsoft Fabric environments: resource consumption monitoring.

Semantic models now continuously report Capacity Unit (CU) consumption during long-running background operations.

Previously, a significant portion of resource usage could be recorded only after an operation was completed.

With the new behavior, surge protection mechanisms can respond earlier, using more up-to-date information about actual resource consumption.

This allows the system to manage high workloads more effectively by delaying or rejecting certain operations when specific thresholds are reached.

The improvement is automatic and does not require configuration changes.

For organizations using shared Fabric capacities, more accurate resource monitoring can help make system behavior more predictable during demanding operations.

In practice

What actually changes in everyday work

The October 2026 update is less focused on major architectural changes than September, but it introduces practical improvements to the Power BI user experience.

The new Gantt chart expands data visualization possibilities, particularly for projects that require tracking activities over time.

Improvements to slicers, Field Parameters, and Personal Bookmarks make reports more flexible and easier to use.

Artificial intelligence also continues to evolve, extending its support to custom visual configuration.

On the semantic model side, continuous Capacity Unit monitoring is a valuable technical improvement for organizations managing Fabric environments with demanding workloads.

Overall, these updates show that Microsoft is working not only to introduce new features but also to improve the efficiency and usability of existing tools.

In summary

In summary

Among the October 2026 Power BI updates, the built-in Gantt chart is probably the most immediately noticeable, as it introduces a new visualization option directly within the product.

Improvements to slicers and dynamic hierarchies can have a practical impact on interactive dashboard design.

The ability to preserve column layouts in Personal Bookmarks makes reports more convenient to use, while new formatting options provide greater control over chart appearance.

Artificial intelligence continues to support development activities, while resource management becomes more accurate in Fabric environments.

As always, there is no need to adopt every new feature. What matters is identifying the improvements that can genuinely enhance report quality and the user experience.
